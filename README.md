## 📌 Overview

**RealSpeed PRO GIGABIT** is an enterprise-grade Android network benchmark and telemetry diagnostic utility engineered from the ground up to solve the inaccuracies of conventional speed tests. Utilizing a **20-second sustained multi-socket transmission pipeline** with **Zero-Fake Anti-ISP Throttling algorithms**, RealSpeed bypasses aggressive ISP burst caches to deliver real-world, gigabit-calibrated bandwidth measurements.

Built natively in modern **Kotlin** and **Jetpack Compose (Material Design 3)** with a futuristic cyber-hud aesthetic, it features real-time oscillograph streaming, network radar analysis, global edge node switching, and local Room database persistence.

---

## ✨ Key Features & Capabilities

### ⚡ 1. 20s Multi-Socket Gigabit Pipeline
* **Anti-ISP Burst Throttling:** Bypasses temporary first-second ISP bandwidth caching with continuous, sustained 20-second multi-thread socket downloads and uploads.
* **True Gigabit Calibration:** Fully supports 0 to 1000+ Mbps Gigabit line measurements with dynamic logarithmic scale curves.
* **Dual Uplink/Downlink Telemetry:** Stage-aware visual indicator badge with real-time countdown.

### 🔮 2. Futuristic Cyber HUD & UI Animations
* **Neon Laser Speedometer:** Multi-color cyber arc sweep with dynamic luminous particle corona.
* **Uplink Transmission Beam:** Distinctive Neon Amethyst theme and kinetic wave pulse during upload tests.
* **Micro-Interactions:** Spring-press physics feedback on interactive buttons, laser shimmer sweeps, and smooth horizontal slide tab transitions.

### 📊 3. Live Oscillograph Waveform Graph
* **Real-time Telemetry Stream:** Cubic Bezier waveform graph capturing micro-fluctuations and buffer spikes.
* **Automated Peak Meter:** Auto-scaling Gbps/Mbps peak indicators with scanner sweep beams.

### 🌐 4. Network Radar & Diagnostics
* **Connection Deep-Dive:** Instant analysis of Wi-Fi standard (Wi-Fi 6/5/4), frequency band (5 GHz / 2.4 GHz), link speed, BSSID, RSSI signal strength, and IPv4/IPv6 gateways.
* **Quality Metrics:** Measures True Ping, Jitter variance, Packet Loss estimates, and Bufferbloat latency under load.

### 🌍 5. Global Edge CDN Multi-Server Routing
* Seamlessly test against low-latency edge servers across Dhaka (Bangladesh), Singapore, Tokyo (Japan), Frankfurt (Germany), and North America.
* **Gigabit Multi-Node Mode:** Parallel multi-server concurrent benchmarking.

### 💾 6. Offline Room Database History & Export
* Comprehensive local test logs with date, time, ping, jitter, download, and upload metrics.
* Real-time calculation of overall network average and peak download performance.

### 👤 7. Developer Support Desk (MD RASEL)
